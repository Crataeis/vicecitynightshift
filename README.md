# Vice City Night Shift

Automated GTA VI highlights channel. Short clips of the most popular public Twitch streams in the
*Grand Theft Auto VI* category are re-cut into vertical format with captions and posted to the
[@vicecitynightshift](https://www.youtube.com/@vicecitynightshift) YouTube channel. Every clip credits
the original streamer in the description.

Streamers who do not want their clips featured can ask for removal and will be added to a permanent
blocklist. Contact: open an issue in this repository.

The software is a small private pipeline (Python, ffmpeg, the Twitch and YouTube Data APIs). It does not
collect any viewer data. See [PRIVACY.md](PRIVACY.md).
